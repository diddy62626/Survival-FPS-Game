# Survival FPS - R3F Edition

A high-performance, multiplayer survival FPS built with React Three Fiber, Cannon-es, and PartyKit.

## Features

- **React Three Fiber Architecture**: Rebuilt from the ground up using R3F for modular scene management.
- **Procedural World Generation**: Seeded terrain chunks with biomes and roads.
- **100+ Zombie Types**: Procedural factory generating 100+ unique enemy variations.
- **Realistic Day-Night Cycle**: Dynamic sun and sky lighting transitions.
- **Advanced Combat**: ADS, reloading, swaying, and walking bob animations.
- **Multiplayer Integration**: Real-time sync, live player list, and kill feed.
- **Performance Optimizations**: Instancing, memoization, and AI tick radius culling.

## Controls

- **WASD**: Movement
- **SPACE**: Jump
- **Mouse Left**: Fire
- **Mouse Right**: ADS
- **R**: Reload
- **ESC**: Release cursor
